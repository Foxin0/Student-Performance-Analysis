From Raw Data to a Structured Data Model

I’m excited to share one of my recent Data Analysis projects, where I worked on transforming raw data into a structured and analysis-ready model using Power Query and Excel.

🔹 The workflow included:

• Preparing and cleaning the source data using Power Query

• Standardizing fields and data types

• Creating separate supporting tables such as:

Grades

Courses

Status

Courses 2

• Structuring the data into a more organized analytical model

• Connecting the tables using Student ID as a common key

• Building the foundation for a proper Power Pivot Data Model

• Preparing the model for future DAX measures, KPIs and interactive dashboards

📈 The dataset contains 94 student records, with information related to students, courses, scores, status, enrollment dates, months and years.

The current data shows:

✅ 70 Passed students

❌ 24 Failed students

📊 Average Score: 53.8

What I learned from this project is that building a good dashboard is not only about creating visuals.

A reliable dashboard starts with clean data and a well-structured Data Model.

This project helped me practice the complete analytical workflow:

Raw Data → Power Query → Data Transformation → Supporting Tables → Data Model → DAX → Dashboard
